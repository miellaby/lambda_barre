# Session 2026-11-08

## Décision actée : un seul calcul du dénouement, le score de soulagement

**Concept unique : relief_score** (score de soulagement). On ne parle plus de favorability.

- Toute séquence porte un token EOS (token du bilan métabolique en position terminale) qui contient le delta des coûts.
- **Format de l'EOS** : delta brut de chaque signal de coût, dans [-1, 1], normalisé en [0, 1] par (d + 1) / 2. Ni amplifié (plus de division par une échelle < 1), ni seuillé (plus de clamp).
- **Définition** : relief_score(sequence) = relief_score(eos(sequence)) = somme pondérée de chaque signal de coût du token EOS (hiérarchie des poids des canaux).
- **Convergence** : tous les concepts dérivés (impact, prioritized sampling, affichages) convergent vers ce calcul. impact = abs(relief_score(sequence)).
- **Échelle** : si relief_score change d'échelle suite à cette évolution, adapter les poids et les seuils dans le code appelant.
