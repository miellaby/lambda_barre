# ADL — Architecture Design Log

Un ADR (Architecture Decision Record) par sujet : ADL/ADR-NNNN-slug.md, numérotation incrémentale (ADR-0001, ADR-0002, ...).

## Template

Chaque ADR comporte :

- Statut : proposé / adopté / remplacé par ADR-NNNN
- Date
- Contexte : le problème ou la question
- Décision : ce qui est acté, en termes canoniques (ADR-0001)
- Conséquences : implications, fichiers concernés (nom de fichier seul suffit)

## Règles

- Un ADR ne se réécrit pas : une décision qui évolue produit un nouvel ADR, l'ancien passe au statut remplacé par ADR-NNNN.
- Docs de conception en français, termes canoniques de ADR-0001. La GUI reste en anglais (voir AGENTS.md).
- Les session_YYYY_MM_DD.md restent des logs chronologiques ; seules les décisions durables passent en ADR.
