# Introduction

**λ̄** is a desktop-pet project for 2027: an animat with simplified morphology, actual machine learning, a world-model transformer, RL on a realistic sensory field, and an innate reward circuit the trainer can leverage to shape the animal's behavior.

This is in a work in progress.

# Install

python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -e .

# Run

.venv/bin/python -m lambda_barre.main
