# Session 2026-11-13 — masque lookahead compact, decision_pos = a4, décalage brain-off corrigé

## Implémenté

- **Masque lookahead unique et compact** : `build_lookahead_mask` (séquence complète) supprimé. Un seul builder `build_lookahead_gen_mask(ctx_len, device, decision_pos)` partagé training/génération. La passe lookahead tourne sur `[contexte, a4 teacher-forcé, EOS]` (`_lookahead_input`, 81 tokens au lieu de 173) — seules les 3 lignes prédictrices de a4 voient l'EOS, l'EOS ne voit que le contexte + lui-même (jamais a4), anti-copie des actions du contexte sur les lignes a4. Le multi-position « toutes les lignes intero voient l'EOS » (résidu du design causal/glissant) est supprimé.
- **decision_pos = premier token de a4** : `n_ctx*16 + STATE_TOKENS` (13), plus `n_ctx*16 + _INTERO_IDX`. Tous les `+1` supprimés (contexte = `vals[:, :decision_pos]`, a4 = `vals[:, dp:dp+3]`, lignes prédictrices = `dp-1..dp+1` car ligne i prédit token i+1). wm_theater, tests et métadonnées recalés.
- **Décalage brain-off corrigé** : `record()` avec `act_conseq_shift=k` enregistre maintenant `(s_n ; a_{n-k})` — action retardée, état courant (avant : état retardé `s_{n-k}` + action courante, ce qui produisait des salves « aller-retour » artificielles). `_state_hist` → `_act_hist`. Au toggle k=0 aucune rupture ; à k=0→k>0 l'action courante est répétée tant que l'historique n'est pas plein.
- **AGENTS.md** : règle « Reload Intro Docs Before Coding » — relire README.md, DESIGN.md, dernière session_YYYY_MM_DD.md et **toutes les entrées de ADL/** avant toute modification de code ; ne jamais affirmer une géométrie de layout de mémoire, citer les lignes (tokenize.py, compute_seq_layout, mask builders, _wm_masked_mse) et dire si un index est une ligne ou un token.
